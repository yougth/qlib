## 一、策略是什么

**一句话**：牛市用 ICW 模型组合（双周调仓进攻），熊市自动把 70% 资金切到 VGH 防御腿——进攻与防御自动切换的"含模型"主策略。

### 1.1 双腿结构

| 市场状态 | ICW 腿（模型进攻） | VGH 腿（规则防御） |
|---|---|---|
| **牛市** | 100% 资金，Top10 | 0% |
| **熊市** | 30% 资金，Top3 | **70% 资金，Top7** |

### 1.2 熊牛判定（宏观阀门，PIT 无穿越）

- 基准：沪深300 收盘价 vs MA60
- **入熊**：收盘价 < MA60 × (1 - 3%) 且连续 3 日确认（带宽 3% + 滞回 3 日，防反复横跳）
- **出牛**：收回均线上沿
- 参数：`TIMING_MA=60, TIMING_BANDWIDTH=0.03, TIMING_HYSTERESIS=3, SWITCH_W_BEAR=0.3`

**当前状态：熊市**（2026-09-09 信号日判定，30% ICW + 70% VGH 配置）。

### 1.3 ICW 腿（模型融合）

- **模型**：XGBoost + LightGBM + DoubleEnsemble 三模型，按 valid RankIC 加权融合
- **ICW** = Integrated Confidence Weighting：融合分 = Σ(model_score × IC_weight)
- **角色定位**（关键设计）：模型不驱动主收益，只在十年双正池内**排雷**（剔价值陷阱）和**挑加速**（选加速度）；value_comp 规则保证"便宜的基本盘"
- 双周调仓（每 10 个交易日），换手较高（回测 65.4%）
- Valid RankIC：XGB 0.088 / LGB 0.053 / DE 0.085

### 1.4 VGH 防御腿

与 `../VGH/上线报告.md` 完全同一套打分（港股 FCF 收益替代估值倒数），此处不重复。

| 分解 | 年化贡献 |

| 择时贡献 | **-1.94pp** |
| **选股 alpha** | **+26.05pp（占 103%）** |
| β系数 | 0.54 |

**解读**：
- 收益几乎 100% 来自选股 alpha（模型融合 + 价值池）
- 择时贡献为**负**（-1.94pp）——熊市切换不是收益来源，是**风控装置**（用小部分收益换回撤收窄 14pp）
- 相对纯模型腿（ICW 双周 Sharpe 1.24）的提升来自回撤控制，不是收益提升

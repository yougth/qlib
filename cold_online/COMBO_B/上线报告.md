## 一、组合是什么

**一句话**：COMBO_A 加 10% 的 LOF 折价腿——**年化只让 0.25 个点（23.86%→23.61%），买进一条与全组合几乎不堵车的新路**（LOF 与 VG 相关 0.071、与 M4 0.186）。这是六腿实验里性价比最高的一笔交易，也是三个上线组合中的**首选推荐**。

| 腿 | 权重 | 角色 | 腿单独表现（同期） |
|---|---:|---|---:|
| ICW_SW | 54% | 主力发动机（含模型，双周调仓） | 24.07% / Sharpe 1.27 / 回撤 -20.5% |
| M4 | 36% | 第二发动机（排雷质量动量月频） | 22.25% / Sharpe 0.92 / 回撤 -37.2% |
| LOF | 10% | **分散器**（月末深折价 Top10，容量利基） | 19.31% / Sharpe 0.98 / 回撤 -35.7% |

- LOF 腿单看平庸（Sharpe 0.98、回撤 -35.7% 与 M4 同深），但它与 ICW_SW **0.374**、与 M4 **0.186**、与 VG **0.071**——是六腿里唯一的"真金"级低相关；
- 加入 10% 后：Sharpe 1.25→**1.29**，Calmar 1.19→1.15（回撤略深 0.5pp），年化让 0.25pp——**用最小的年化代价买风险结构**。

## 三、收益来源

- ICW_SW + M4：A 股选股 alpha 双发动机（与 COMBO_A 相同）；
- LOF：**场内基金折价收敛 + 流动性补偿**——买"市场因流动性差而打折"的 LOF，等折价修复。它与股票选股 alpha 几乎不共享风险因子（相关 0.07~0.19），提供的分散是"结构性的"而非"统计巧合"；
- 注意 LOF 的容量利基：池日中位成交额 ~104 万，机构进不来——这也意味着**它只适合小额资金**（10% 权重、5 万级没有压力）。

## 七、已知风险与简化假设

1. **网格事后寻优**（同 A）：54/36/10 是挑出来的；
2. **LOF 流动性风险**：单只 LOF 日成交额中位 104 万，10 万级资金ok，再大就会打穿盘口；极端日折价可能先加深再修复（LOF 腿自身回撤 -35.7%）；
3. **腿间再平衡成本未计**（0.3~0.8pp/年）；
4. **分红未入账**（约 -1~2pp/年）；
5. **接力建仓口径**：三腿均用最新一期信号在 9/18 建仓（非各自调仓日 T+1），影响仅限首期；
6. **危机相关性**：2024 初微盘踩踏时段 M4 与 LOF 同向深跌（-35% 级同深），历史 0.19 的低相关不保证危机日赔付；真保护仍靠仓位控制。

# 策略说明书（小白版）—— 你的钱到底是怎么选股的

> 面向对象：量化零基础的你自己。
> 对应代码：`qlib/online_value/`（实盘）与 `qlib/quant/`（研究）。
> 所有数字均核对自代码与 `RUNBOOK.md`，截至 2026-07-31。

---

## 0. 一句话总结

**每个月最后一个交易日晚上，从"连续十年既赚钱又有真金白银流入"的约 300 家公司里，挑出最便宜的 20 家，下个月第一个交易日尾盘买入，每只占 5%，然后一整个月什么都不做。**

回测成绩（2019–2026，跳过 2020）：**年化 25.7%，最大回撤 -19.9%，同期沪深300 年化只有 3.3%**。

这就是全部。下面解释每个字为什么这么定。

---

## 1. 先扫盲：几个绕不开的词

| 术语 | 大白话 |
|---|---|
| **股票池（universe）** | 允许买的股票范围。先划个"好学生名单"，再从里面挑，避免踩雷 |
| **因子（factor）** | 给股票打分的一个维度。比如"便宜程度"就是一个因子 |
| **PE / PB / PS / PCF** | 四种"贵不贵"的尺子：股价相对利润 / 净资产 / 营收 / 现金流的倍数。**越低越便宜** |
| **FCF（自由现金流）** | 公司一年真正落袋的现金。利润可以"编"（应收账款、会计调节），现金流最难造假 |
| **回测（backtest）** | 拿历史数据假装从过去开始执行这套规则，看能赚多少。是策略的"模拟考试" |
| **年化收益** | 把总收益折算成"平均每年赚多少"。25% 年化 ≈ 3 年翻一倍 |
| **最大回撤** | 从最高点跌到最低点的最大跌幅。-19.9% 意味着你要能忍受账户缩水五分之一而不砍仓 |
| **夏普比率（Sharpe）** | 每承担一份波动换来多少收益。>1 算好策略 |
| **前视偏差（look-ahead bias）** | 回测作弊：用了"当时还不知道"的信息。比如 4 月就用当年年报选股（年报 4 月底才公布完）。**这是回测第一大坑，本项目为防它做了 6 层机制** |
| **PIT（point-in-time）** | "当时视角"：只用决策那一刻真实可得的数据 |
| **IC / RankIC** | 打分和未来涨幅的相关性，衡量"分数到底有没有预测力"。0.05 以上就算有用信号 |
| **IS / OOS** | In-Sample（样本内，调参用的年份）/ Out-of-Sample（样本外，从没用来调参的年份）。**OOS 成绩才算数**，IS 好看可能只是"背题" |

---

## 2. 第一步：股票池 —— "十年双正"名单

### 规则

一家公司要进入候选名单，必须**过去十年（Y-11 到 Y-2 年）每一年都满足**：

1. **自由现金流（FCF）> 0** —— 十年里每年都有真金白银流入
2. **净利润 > 0** —— 十年里每年都赚钱（净利数据从 2016 年起才全覆盖）

数据覆盖不足 80% 年份的剔除。两个条件取交集，2026 年满足的约 **303 只**（全市场 5000+ 只里的前 6%）。

### 为什么用 Y-2 而不是去年的年报？

这是全项目最重要的防作弊细节：**2025 年的年报要到 2026 年 4 月 30 日才披露完**。如果 2026 年 1 月就用 2025 年报选股，等于用了未来信息，回测会虚高、实盘会翻车。所以在 2026 年交易时，最多只敢用 **2024 年（Y-2）及更早**的年报。宁可数据旧一点，也绝不作弊。

> 代码位置：`online_value/core/universe.py` 的 `build_dynamic_universe`。

### 这一步在整个策略里贡献了什么？

它把"选股"变成了"在好公司里选便宜的"。十年双正是极苛刻的质量筛子——能连续十年现金流和利润双正的公司，基本排除了讲故事的、造假的、周期性巨亏的。回测里**光是把这个池子等权拿着**，就已经能跑赢很多策略。

---

## 3. 第二步：打分 —— value_comp（越便宜分越高）

对池子里每只股票，取四个估值指标的倒数：

- **EP** = 1/PE（盈利收益率）
- **BP** = 1/PB
- **CFP** = 1/PCF
- **SP** = 1/PS

每个指标在池内做**排名百分位**（最便宜的接近 1，最贵的接近 0），四个百分位**取平均**，就是 `value_comp` 得分。

**为什么用排名而不是原始值？** 四个指标量纲不同（PE 十几倍、PB 几倍），直接平均会被某一个绑架；排名后全部变成 0~1，公平合成。这也让个别极端值（比如 PE=2000 的异常股）不会污染整体。

**为什么不加动量、不加机器学习？** 加过，试了十几个版本，全部被否——详见《策略演进史》。一句话：在这个 300 只的优质池子里，**"买便宜的"是唯一稳定有效的信号**，其它花活要么没增量、要么增加回撤。

> 代码位置：`online_value/core/valuation.py` 的 `compute_value_comp`。

---

## 4. 第三步：过滤 —— 三种买不了/不该买的剔掉

打分之后、选前 20 之前，剔除：

| 过滤 | 规则 | 为什么 |
|---|---|---|
| 流动性不足 | 20 日平均成交额 < 500 万元 | 买不进卖不出，回测成绩是纸面财富 |
| 涨停（一字板） | 开=高=低=收 且涨幅>9% | 根本买不到 |
| 停牌 | 当日无成交量 | 同上 |

> 小坑备忘：qlib 里 `$volume` 的单位是**手**（=100股），算成交额要 ×100。代码里 `LIQ_THRESHOLD = 5_000_000 / 100` 就是这么来的，别看着 5 万觉得写错了。

---

## 5. 第四步：组合 —— Top20 等权，月频换仓

- **持仓**：得分最高的 20 只，每只 5%
- **信号日**：每月最后一个交易日（收盘后算清单）
- **执行日**：下月第一个交易日 **14:45–14:55 尾盘**，限价单
- **换手**：每月实际只换 2~4 只（月均单边换手约 15%）
- **成本**：回测已扣往返 0.4%

**为什么是 20 只？** 少了赌性太大（Top10 版本回撤 -34%），多了收益被稀释。20 只等权 = 单只最多伤你 5%。

**为什么月频？** 季频训练样本太少、反应太慢；周频换手成本吃掉利润。月频是实测出来的平衡点。

**为什么尾盘买？** 回测按"次日收盘价成交"计算，尾盘 14:45 的价格最接近收盘价，实盘和回测的偏差最小。

### 明确"不做"清单（每一条都是实测否决过的）

- ❌ **不用机器学习模型**（V14 消融实验：XGB 排序是 **-10.69pp 的负增量**）
- ❌ **不剔除金融股**（V19 实验：剔了银行保险 OOS 反而 **-4.53pp**）
- ❌ **不择时、不止损、不止盈**（-19.9% 回撤是回测就有的，止损会切掉反弹）
- ❌ **月中不因任何消息动仓位**

## 6. 成绩单

**回测锚点（2019–2026，跳过 2020 疫情异常年）：**

| 指标 | 数值 |
|---|---|
| 年化收益 | **25.75%** |
| 年化波动 | 20.4% |
| 夏普 | **1.26** |
| 最大回撤 | **-19.9%** |
| Calmar | 1.28 |
| 交易笔数 | 262 |
| 样本内 IS（2019/21/22） | 21.69% |
| **样本外 OOS（2023–26）** | **29.28%** |
| 沪深300 同期年化 | 3.28% |

逐年：2019 +27.9% ｜ 2021 +31.8% ｜ 2022 +4.6% ｜ 2023 +36.3% ｜ 2024 +40.5% ｜ 2025 +26.6% ｜ 2026（前7月）-0.5%。

两个最值得记住的点：

1. **OOS（29.3%）比 IS（21.7%）还高** —— 说明不是靠"背历史题"拟合出来的。
2. **2022 年大熊市（沪深300 -21.6%）它还 +4.6%** —— 便宜+优质的组合抗跌。

也要记住丑话：**它出现过 -19.9% 的回撤，2026 年前 7 个月是负的。** 未来某年跑输大盘、连跌半年都是正常剧本，剧本之内的事不需要任何操作。

## 7. 为什么敢信这个回测？——6 层防作弊 + 3 层防漂移

### 防作弊（回测不虚高）

1. 股票池只用 Y-2 及更早的年报（防年报前视）
2. 训练/验证/测试按时间硬切，12 月留白（embargo，防标签泄漏）
3. 预测目标只用未来数据定义，特征只用过去数据
4. 标准化参数只在训练段拟合
5. 估值/基本面因子按"披露日之后"才生效
6. T+1 执行：今天的信号明天才能成交

### 防漂移（实盘=回测，代码不被悄悄改坏）

1. **代码指纹锁**：实盘 14 个核心文件的 md5 全部锁定，改一行注释都会报警
2. **黄金持仓锁**：2026 年 7 期 × Top20 历史持仓锁死，每月重算必须逐行一致——历史不得被改写
3. **历史数据指纹**：88 万行估值数据 + 抽样行情的指纹锁定，上游数据被回填/改写立刻发现

每月交易前跑 `preflight_check.py` 做 **18 项体检**，任何一项 FAIL 当月禁止交易。`gen_holdings.py` 会强制检查"今天体检全过"才肯出清单——想绕都绕不过去。

## 8. 每月操作流程（照抄 RUNBOOK 即可）

```
D-1 晚（月末最后交易日 18:00 后），三条命令依次跑，上一条 EXIT=0 才跑下一条：
  ① python3 monthly_update.py     # 更新数据
  ② python3 preflight_check.py    # 18 项体检
  ③ python3 gen_holdings.py       # 出 Top20 + 5 只备选清单

D 日（下月首个交易日 14:45–14:55）：
  先卖不在新清单里的 → 再买新进的，限价单（买 ×1.005 / 卖 ×0.995）
  涨停/停牌买不进 → 按备选顺延，不追高

之后一整月：什么都不做。
```

**所有异常的默认动作都是"不交易，保持原持仓"** —— 漏一次换仓的代价，远小于按错误数据换仓。

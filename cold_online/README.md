# cold_online —— Paper Trading 策略冷启动观察区

**目录定位**：所有已进入 Paper Trading（虚拟盘）验证的策略档案。每个策略一个子目录、一份《上线报告.md》，记录从离线策略定义到上线判定的全部证据链。**目标：积累多个策略的纸面验证实例后，从中总结出可复用的"上线判定规则"——满足什么条件，一个策略可以从这里毕业进入实盘。**

**建立日期**: 2026-09-20

## 三、运行链路（数据到台账）

| 环节 | 命令/文件 | 频率 |
|---|---|---|
| 每日盯市（六腿+组合） | `cd qlib/quant && bash live/daily_mark.sh`（~1-2 分钟：股票/ETF/LOF 行情 → 六腿盯市 → 组合加权）或刷新看板自动同步 | 每交易日 |
| 新三腿单独盯市 | `cd qlib/new_quant && python3 -m experiments.live_pt --leg M4 --mark`（LOF/TREND 同理；盘中自动用实时价标 intraday） | 每交易日 |
| 组合层重算 | `cd qlib/quant && python3 live/combo_track.py --mark`（幂等）；`--report` 查看三组合报表 | 腿台账更新后 |
| Web 看板 | `cd qlib/quant && streamlit run live/dashboard.py`（localhost:8501）；覆盖六腿 + 三组合（COMBO_A/B/C），刷新即自动同步全链路 | 常驻 |
| 换仓（ICW_SW 双周） | `cd qlib/quant && bash live/rebalance.sh 2026-09-23 ICW_SW` | 每 10 交易日 |
| 换仓（VG/VGH 月末） | `cd qlib/quant && bash live/rebalance.sh 2026-09-30 ALL` | 每月末 |
| 换仓（M4/LOF/TREND 月末） | `cd qlib && python3 new_quant/experiments/live_pt.py --leg {M4,LOF,TREND} --signal` → 执行日 `--fill <日>` | 每月末信号 / 节后执行 |

链路顺序（旧三腿换仓）：A 股行情更新 → 重建 bin + 港股 quotes 刷新 + 合并 → 估值缓存重建 → 信号生成 → T+1 模拟成交 + 盯市。  
新三腿换仓：数据刷新（`tools/fetch_etf_ohlcv.py` / `tools/fetch_lof.py` / `update_ohlcv_bs.py`）→ `live_pt.py --signal` → 执行日 `--fill`；组合层任何腿盯市后重算 `combo_track.py --mark` 即可（幂等）。

台账：`qlib/quant/live/ledger/{ICW_SW,VG,VGH,M4,LOF,TREND,COMBO_A,B,C}/`（state.json + trades.csv）  
信号：`qlib/quant/live/signals/{日期}/{策略}/`；新三腿信号另存 `qlib/new_quant/outputs/pt_signals/`

## 四、上线判定规则（草案 v0.1 · 随实例持续修订）

> 本节是 cold_online 的核心产出：**从纸面验证中提炼"什么条件满足才上实盘"**。当前规则综合自 V18 上线方案（2026-09-10）与首期 Paper Trading 暴露的实际问题。随策略实例积累逐条修订，修订需注明日期与依据。

### 4.1 硬性前置条件（Gate，一票否决）

| # | 条件 | 现状 |
|---|---|---|
| G1 | **数据链路稳定**：Paper Trading 期间无未修复的数据断供（行情/估值/基本面） | ⚠️ 港股曾断供 2 个月（07-23~09-16），已修复，观察期重新起算 |
| G2 | **回测基线口径唯一**：分年收益、年化、交易次数在所有文档中一致 | ❌ 旧三腿双口径冲突（剔20 年化差 1.7~3.5pp），须统一重跑；组合层不受影响（统一重跑基线） |
| G3 | **执行可行性**：模拟的每手股数、最小下单金额与真实市场规则一致 | ❌ 港股按 100 股/手模拟，实盘前必须改为真实手数表 |
| G4 | **信号可复现**：同一信号日重跑（同代码同数据）订单一致，模型 SHA256 校验通过 | ✅ 已具备（冻结模型 + config hash 校验） |

### 4.2 统计验证条件（观察期 ≥ 3 个月）

| # | 条件 | 判定口径 |
|---|---|---|
| S1 | 实盘 Sharpe ≥ 回测 Sharpe × 0.8 | 滚动 3 个月日收益计算 |
| S2 | 最大回撤 ≤ 回测最大回撤 × 1.2 | 建仓起累计 |
| S3 | 实盘与回测同期年化偏差 ≤ 5pp | 以回测同期逐日净值对照 |
| S4 | 滑点偏差 ≤ 0.5pp/年 | 模拟成交价 vs 实际可成交价对比（换手越高越关键） |

### 4.3 分层判定（不同策略不同门槛）

| 层 | 适用 | 额外条件 | 仓位定位 |
|---|---|---|---|
| L1 纯规则稳健 | VG | S1~S4 达标即上线 | 底仓（资金占比高） |
| L2 纯规则防御 | VGH | S1~S4 + 港股执行可行性（G3） | 底仓 |
| L3 含模型进攻 | ICW_SW / COMBO_A / COMBO_B / COMBO_C | S1~S4 + **模型漂移监控**（月度 IC 衰减 <30%）+ 双倍观察期（6 个月） | 增强仓（初始 ≤30%）；组合层按所依赖腿的最高风险层判定 |

### 4.4 止损与降级规则（上线后持续）

| 触发 | 动作 |
|---|---|
| 实盘 Sharpe < 回测 × 0.5 | 暂停加仓 |
| 回撤 > 回测 × 1.5 | 减仓 50% |
| 连续 3 月年化偏差 > 5pp | 停止该策略 |

### 4.5 资金爬坡（上线后）

第 1 个月 10% 目标资金 → 第 2-3 个月 50% → 第 4-6 个月 100%。纯规则 70% / 含模型 30% 起步，L3 达标后可提至 50%。
